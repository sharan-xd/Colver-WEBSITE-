# Colver — Agent Operating Manual (ECC)

## Operating Standards
- Follow ECC standards for all code additions and updates.
- Keep files small and functions concise.
- Validate inputs at all boundaries.
- Adhere to conventional commits format (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`).
- Verify build and type integrity (`npm run lint`, `npm run build`) before delivering work.
